> The streetlight clicks on exactly as I pass under it, and for one
> block I get to pretend the city noticed me.

## Run

```sh
python3 main.py
```

This writes the sentence verbatim (UTF-8, no trailing newline) to
`/output/entry.txt`. Python 3.13, standard library only, no network,
no randomness — two runs produce byte-identical output.
